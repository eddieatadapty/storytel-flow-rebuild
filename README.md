# Storytel Growth Audit

**Live → https://eddieatadapty.github.io/storytel-flow-rebuild/**

Five ideas to turn more Storytel users into subscribers, each built into a clickable version of Storytel's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | One paywall screen, not three | +10–15% CR to trial start |
| 02 | Explain the free week before they commit | +5–10% CR to trial start |
| 03 | Make annual the easy yes | +10–15% ARPU |
| 04 | Use the languages they just picked | +5–10% CR to trial start |
| 05 | Catch the people who close | +3–8% CR, recovered from closers |

Every price, rating and feature comes from Storytel's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Storytel. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
